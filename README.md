# 上岸莫卷 · 粉笔答题界面

把粉笔题库的答题页（`spa.fenbi.com/ti/...`）换上一套「墨卷」皮肤：纸 / 墨双主题、限宽阅读版心、题面衬线排版、选项与判分状态更清楚，同时**完全保留粉笔原有的答题、判分、交卷逻辑**。

## 它做什么 / 不做什么

**做：**
- 纸（暖白）/ 墨（夜读）双主题，直接重写粉笔自己的 `--color-*` 设计令牌，页头、题卡、答题卡、解析区一起变色，不是只盖一张卡片。
- 题面使用衬线大字，行高 1.95；选项改为「一张卷子里的行」，字母徽章 + 清晰的选中 / 正确 / 错误 / 漏选状态。
- 左下角一枚低存在感工具胶囊：切换主题、切换字号、专注模式、打开「考场三件事」。
- 阅读区限宽约 980px 并居中，长材料不会一行铺满整块屏幕。
- 底部答题卡抽屉重新配色、收窄并限制高度，已答 / 正确 / 错误一眼可分。

**不做：**
- 不读取、不存储你的答案。
- 不拦截、不修改任何点击、判分与交卷。
- 不扫描 A/B/C/D 文本、不给题目节点增删 class、不监听 class 变化。
- 不访问粉笔接口、不碰登录态、不依赖网络。

## 设计语言：墨卷

| | 纸 | 墨 |
| --- | --- | --- |
| 底色 | 暖白纸 `#F2EDE2` | 墨蓝黑 `#111418` |
| 主墨 | `#211D17` | `#E9E3D6` |
| 朱砂（题号 / 强调） | `#9E3B2C` | `#C9614C` |
| 靛青（当前选中） | `#2F4C6B` | `#93AED6` |
| 松绿（正确） | `#3E6B52` | `#6FAE8B` |
| 赭红（错误） | `#A8432F` | `#D8695A` |

排版上，默认题面用宋体 / 思源宋体，选项跟随阅读字体设置；数字与英文标签用等宽字体。弹窗内还可切换黑体、楷体或导入自己的字体。整体去掉了上一版的霓虹光晕、噪点覆盖和超大数字水印，改成更耐读的纸面感。

扩展弹窗底部还加入了「作者的其他应用」推荐区，提供墨集、流光阅历、墨园、WPS 福利自动助手、打水漂大师的快捷入口；图标使用作者应用页的真实图标本地副本，点击会在新标签页打开对应作品页，也可以一键进入全部应用页面。

## 安装（Chrome / Edge，约 1 分钟）

### 方式一：使用现成 ZIP（最简单）

1. 从本仓库文件列表下载 `shangan-mojuan-v2.7.0.zip`。
2. 右键 ZIP → 「全部解压缩」，得到文件夹 `shangan-mojuan-v2.7.0`。
3. 地址栏打开 `edge://extensions/`（Edge）或 `chrome://extensions/`（Chrome）。
4. 打开右上角「开发者模式」。
5. 点「加载已解压的扩展程序」，选择刚解压的文件夹（包含 `manifest.json` 的那一层）。
6. 打开粉笔答题页刷新即可。

> ZIP 内已包含全部运行文件，不需要安装依赖，也不需要构建。

### 方式二：直接加载仓库源码目录

1. 地址栏打开 `edge://extensions/` 或 `chrome://extensions/`。
2. 打开「开发者模式」。
3. 点「加载已解压的扩展程序」，选择仓库根目录（包含 `manifest.json` 的那一层）。
4. 打开粉笔答题页刷新即可。

## 使用

- **扩展弹窗**：启用 / 关闭、纸 / 墨主题、正文字号（小 / 标准 / 大）、阅读字体（宋体 / 黑体 / 楷体 / 自定义导入）、行高与字重。
- **应用推荐**：弹窗底部「作者的其他应用」卡片区，带小图标与平台 / 用途标签；点击任一应用即可跳转到作者对应作品页面。
- **检查更新**：弹窗顶部有「检查更新」按钮，打开弹窗时也会自动检查；发现新版后显示更新卡片，可下载新版 ZIP 或忽略此版本。检查结果缓存 24 小时，避免频繁请求。
- **左下角工具胶囊**：鼠标移上去提亮；月亮/太阳切换主题，`A` 切换字号，取景框图标切换专注模式，书本图标打开「考场三件事」；胶囊下方的小减号可手动收起。
- **专注模式**：自动把浏览器窗口切到全屏（等同 F11），收起底部答题卡，阅读区放宽到 880px；可从弹窗、工具胶囊或 `Alt + M` 切换。进入专注时会短暂提示「按 F11 返回」，胶囊自动收成加号；按 F11 可退出浏览器全屏，也可再用 `Alt + M` 或工具胶囊关闭专注状态，退出后恢复胶囊并在下方显示减号。
- **快捷键**：`Alt + T` 切换主题，`Alt + M` 专注模式，`Esc` 收起提示面板，`F11` 退出浏览器全屏（浏览器原生快捷键）。
- 工具轨只在识别到题目（`app-ti` / `app-question-choice`）时出现，不会出现在粉笔首页或题库目录页。
- **资料分析**：沿用粉笔原生左右分栏，默认按 50 / 50 等宽铺满，单题高度约等于一屏；拖动中间把手仍可自由调整，窄屏自动回退为上下排列。
- **答题卡**：默认折叠成右下角小标签，点击展开 / 收起；展开后仍贴右下角，不再跳到屏幕中央，也不会随滚动自动折叠。

## 界面没变化怎么办

1. 确认地址是答题页：`https://spa.fenbi.com/ti/...`。
2. 在扩展管理页点「重新加载」，再刷新页面。
3. 确认扩展弹窗抬头显示的是当前版本号（如 `v2.5.4`），并检查 `edge://extensions/` 里没有重复条目。

### v2.5.6 — 解析页跟随阅读字体

1. **解析区字体**：交卷后的对答案页面用的是另一套组件（`app-result-common`），此前不在字体作用范围内，所以「解析 / 来源 / 我的作答 / 子题答案」仍是粉笔默认字体；现在统一跟随扩展里选的宋体 / 黑体 / 楷体 / 自定义字体。
2. **同页统一**：「解析 / 考点 / 来源 / 笔记」小标题与考点标签也一并换成阅读字体，避免一页里出现两种字。
3. **字号与节奏**：解析正文使用选项字号（`--gk-opt`）和同一套行高变量，切换正文字号或行高时解析区会一起变化。

### v2.5.5 — 专注模式联动全屏

1. **专注即全屏**：开启专注模式时，扩展把当前浏览器窗口切成全屏（等同按 F11，隐藏地址栏与标签栏）；退出专注模式时恢复进入前的窗口状态（最大化 / 普通）。
2. **不抢占全屏**：如果进入专注前窗口本来就是全屏，退出时不会擅自退出；刷新页面时也不会突然进入全屏。
3. **实现方式**：内容脚本只在专注状态真正切换时通知后台，后台用 `chrome.windows.update` 设置窗口状态，不依赖 F11 模拟按键。

### v2.0.0 — 重写实现 + 墨卷视觉

1. **修复答题页卡死**：上一版 `probe()` 每轮增删 class，而 MutationObserver 监听 class 变化，形成无限自触发循环，题目一多页面直接无响应。本版不再给题目节点增删 class，只观察 `childList`，从根上消除循环。
2. **识别方式改为真实组件**：不再全文扫描 A/B/C/D 单字母，改用粉笔真实结构 `app-ti`、`.question-choice-container`、`.choice-radio-label`、`.input-radio`、`.answer-btn`。
3. **换肤方式改为设计令牌**：重写粉笔的 `--color-*` 变量，整个答题页一起变色，减少 `!important` 与样式打架。
